このページは 湖畔のフィッシング の内部パラメータと計算式を、実装（src/）そのままに解説したものです。 魚と装備の表は ゲーム本体のデータファイルを読み込んで生成しているので、常に実際の値と一致します。 計算式は src/game.js の該当箇所をそのまま引用しています。

0単位と記号

長さ

ワールド 1 単位 = 1 m。魚の全長は cm。水深 m。

時間

式の dt は実時間の秒。実 1 秒 = ゲーム内 1 分（1 時間 = 実 1 分、1 日 = 実 24 分）。

0〜1 の量

テンション比と体力は 0〜1 の内部値で、HUD のバーはそのまま％表示。残り距離だけは実際のメートルで、バーは「掛けた距離＋16m」を上限にした割合。

以下、sp は魚種データ、rod/line/bait は装備データ、F はファイト中の状態を指します。

1ファイト — 4つのメーターの正体

ヒット後の駆け引きは、次の 4 つの状態量だけで決まります。毎フレーム、この 4 つが更新され、 3 つの終了条件のどれかに触れた瞬間に決着します。

ラインテンション

F.tension / line.cap

糸に掛かっている張力。巻くと増え、離すと減る。line.cap（糸の強さ）に達した瞬間にラインブレイク。

残り距離

F.dist（実際のメートル）

魚までの距離（m）。ヒット時は掛けた距離そのままで始まり、巻けば減り、放せば魚に引かれて増える。掛けた距離＋16m（糸の 62m 上限まで）で逃走／0.7m で取り込み。近くに掛ければ寄せる距離も短い。

魚の体力

F.stamina（1 → 0）

魚のスタミナ。テンションを掛けている間だけ減る。減ると引く力が弱まり、突進しなくなり、水面に浮いてくる。

突進（ラン）

F.running / runTimer

周期的に発生する暴れ。発生中は引く力が 2 倍。「走った！」の表示中に巻くと一気にテンションが上がる。

毎フレームの更新式（実装そのまま）

// 引きの強さ。突進中は2倍、体力が尽きると半分になる
pull = F.pull0 * (F.running ? 2.0 : 1.0) * (0.5 + 0.5 * F.stamina)

// 糸が短いほど衝撃を吸収できない＝テンションが跳ねやすい（14m 以上で 1.0）
shortLine = clamp(1.35 - F.dist * 0.025, 1.0, 1.35)

if (巻いている) {
  resist  = clamp(1.70 - pull * 0.75, 0.35, 1.60)   // 強い魚ほど巻けない
  F.dist    -= rod.reel * 4.2 * resist * (1 + F.dist * 0.012) * dt   // m/s。遠いうちは速い
  F.tension += (0.08 + pull * 0.55) * shortLine * dt / rod.power
} else {
  F.dist    += pull * 0.70 * dt                     // 出る糸は距離に関係なく m/s
  F.tension -= (1.30 + pull * 0.30) * dt
  if (F.running) F.tension += pull * 0.30 * shortLine * dt   // 走られると放しても張る
}
F.tension = clamp(F.tension, 0, line.cap * 1.2)

// 体力：テンション比が高いほど速く削れる
tRatio = clamp01(F.tension / line.cap)
F.stamina -= (0.022 + tRatio * 0.17 + (巻いている ? 0.02 : 0)) * dt / max(0.4, sp.sta)

// 決着
if (F.tension >= line.cap) → ラインブレイク
if (F.dist >= F.span)     → 逃走（F.span = 掛けた距離 + 16m）
if (F.dist <= 0.7)          → 取り込み

ファイト中は魚種とレア度を伏せています。パネルの見出しは代わりに pull0（= 種の str × サイズ係数）から求めた手応えを表示します： 軽い引き（<0.55）／まずまずの引き（<1.0）／強い引き！（<1.6）／かなり重い…！（<2.4）／とてつもない重さ…！。 サイズも含まれるので大きなコモンも「重い」になり、レア度は推測できません。 ヒット時のメッセージ・突進の警告・エラ洗いの発生も、レア度ではなく pull0 を基準にしています。

ファイトの型（魚種ごとの振る舞い）

魚種には fight で 型が1つ割り当てられています。型は上の更新式に掛ける倍率と追加イベントだけで、 新しいメーターや操作は増えません（1.0 なら従来と同じ挙動）。 fight が無い魚種は fightPattern() がタグ・体型から自動で決めます。

ジャンプの扱い

ジャンプは突進の途中で発生し、跳ね終わるまで突進が終わりません。 つまり「走ったら糸を送る」という基本ルールを守っていれば自動的に対応できます。 送れていれば魚が余計に消耗し（jumpDrain /秒だけ体力が減る）、 巻いたままだと張力の増加が jumpTension 倍になります。

首振りの扱い

数値そのものを揺らすのではなく、振っている間だけ巻き取り効率が shakeReel 倍に落ち、張力の増加が shakeGain 倍になります。 メーターは正直な値のままなので「振っている間は手を止める」という判断が生まれます。

型はレア度が偏らないように割り当てています（各型にコモン〜レア以上が混在）。 ファイト中に型が分かってもレア度や魚種は特定できません。

質問への回答

Q. 「魚の体力」とは？ 減ると何が起きる？ 魚のスタミナ F.stamina（1 → 0）です。テンションを掛けている間だけ削れ、 減ると次の 3 つが同時に起きます。
  • 引く力が落ちる：pull の係数 (0.5 + 0.5×stamina) が 1.0 → 0.5 に。つまり最大で半減。 引きが弱まると resist が上がるので巻き取り速度も上がり、加速度的に楽になります。
  • 突進しなくなる：stamina ≤ 0.16 で新しいランが発生しません。
  • 浮いてくる：見た目の泳層が lerp(0.35, 2.4, stamina) m と浅くなり、水面で暴れる演出になります。
減る速さは ÷ max(0.4, sp.sta)。つまり sp.sta（体力値）が大きい魚は「粘る」＝弱らせるのに時間が掛かります。 テンション比 0.7 を維持した場合の目安は (0.022 + 0.7×0.17 + 0.02) / sta ≒ 0.16 / sta /秒 → sta 1.0 の魚なら約 6 秒、sta 3.2 の湖の主なら約 20 秒でスタミナ切れ。 逆にテンションを掛けずに待っても魚は疲れません（0.022/sta しか減らない）。
Q. 「糸の強さ（line.cap）」とは？ テンションの上限＝切れる値そのものです。HUD のテンションバーは tension / cap を表示しているので、 cap が大きい糸は「同じ表示％に達するまでの余裕が大きい」＝巻ける時間が長くなることを意味します。
  • ナイロン 1.00 → ミスリル 2.80 で、切れるまでに耐えられる張力が 2.8 倍。
  • 張力の増加は (0.08 + pull×0.55) / rod.power /秒。0 から cap に達するまでの秒数は cap × rod.power / (0.08 + pull×0.55) です。
  • 体力削りは tension / cap の比で効くため、強い糸ほど「安全な範囲で強く引ける」＝魚を早く疲れさせられます。
Q. ロッドの「竿の力（power）」「巻取（reel）」の違い？ power はテンションの増加を割り算で抑える値（＝竿が引きを吸収する）で、tension += … / rod.power。 reel は巻き取り速度の倍率で、dist -= rod.reel × 4.2 × resist × (1+dist×0.012) × dt（m/s）。 power は「切れにくさ」、reel は「早さ」に効きます。ラインブレイクを減らしたいなら line.cap と rod.power、 ファイトを短くしたいなら rod.reel です。attract はファイトには無関係（アタリの速さと抽選）。
逃走は「掛けた地点より 16m 走られる」ことで起きます。 放している間、距離は pull × 0.70 m/秒で増えます。強い魚の突進中（pull が 2 倍）は 放すだけで毎秒 4m 以上取られることもあり、巻き取り（rod.reel×4.2×resist）が それを下回る装備だとどう操作しても逃げられます。これが装備の壁です。

🐟 アタリ抽選の確率

タナ（狙う層）を決める — 生息水深 × 遊泳層

魚のデータは2 軸に分かれています。 生息水深（depth）はその魚が居る場所の水深、 遊泳層（layer）は水中のどの層で食うかです。 プレイヤーは E の仕掛けウインドウで 表層／中層／底層 の 3 択を選び、 抽選では「その場所の水深が合っているか」×「その層で食うか」の両方が掛かります。

なぜ 2 軸なのか

1 軸（生息層だけ）だと 水深 20 m の水面下 3 m と 水深 3 m の底 を区別できず、深場の表層でドジョウが釣れてしまいます。 また「浅場に居るが表層で食う魚」（ライギョ）と「浅場の底に居る魚」（ザリガニ）を書き分けられません。

タナの実際の深さ

clamp(水深 × 比率, 0.35, 水深 − 0.35)。 比率は表層 15% / 中層 50% / 底層 88%。この深さは見た目（仕掛けの位置）と底層のゴミ判定に使い、 魚の抽選には⑥の遊泳層の重みを使います。

時間帯で釣れる深さが変わる（日周移動）

現実の湖では、多くの魚が1 日のうちで泳ぐ深さを変えます。代表的なのは 日周鉛直移動（diel vertical migration）で、動物プランクトンが昼は捕食者を避けて深みに沈み、 夜に浮上するのに合わせて、それを食べる魚も同じように上下します（ワカサギの氷上釣りで 「昼は底、朝夕は浮く」と言われるのはこれ）。ほかにも

  • 朝夕のマズメ：鱒類・ブラックバスは水温と光量が落ちる朝夕に浅い層へ差して水面を意識し、日中は深い層・カバーの底に落ちる
  • 夜の接岸：ナマズ・ウナギ・コイ・エビ・カニは夜になると浅場へ出て餌を探し、日中は深場の底や穴に潜む
  • 逆パターン：ライギョは変温動物で日中の高水温を好み、昼に水面のカバーで浮いている。夜は沈む
  • 夜明けの一瞬：白龍魚（架空）は夜明けだけ水面を割る、というフレーバーをそのまま実装に落としている

実装は 2 つの入口を用意しています。層が入れ替わる魚は layer を時間帯ごとの表にし、 浅場と深場を行き来する魚は diel（−1 で浅場寄り 〜 +1 で深場寄り）で 生息水深の帯そのものを上下させます（ずれ幅は帯の 35%）。両方持つ魚もいます。

目安にはなる

まわりを泳ぐ 22 匹も同じ rollSpecies(水深) で湧いているので、 見えている魚種＝その場所・その時刻に釣れる魚の目安になります。最初は自分の周り 6〜52 m に配置され、 78 m 以上離れる／水深 0.35 m 未満に乗り上げると 26〜58 m 先へ入れ替わります。

ただし条件は違う

5キャストの物理

キャストは「狙った距離に当てる」操作です。視線が水面と交わる点が狙い点で、そこに水色の輪が出ます。 メーターの緑の帯はその距離に必要なパワーの位置。帯の中で離すと狙い通りに落ちます。 

// ① 狙い点：視線と水面(y=0)の交点。見下ろすほど近く、水平で遠く
狙い距離 = clamp(視線が y=0 に達する水平距離, 最短キャスト, 50) m

// ② 目印：その距離に落ちるパワーを弾道の逆算（二分探索12回）で求める
仰角成分 = clamp(0.46 + pitch × 0.55, 0.16, 0.95)
初速     = lerp(4.5, 28.5, power) m/s
毎フレーム: v.y −= 9.8·dt ;  v ×= (1 − 0.0055·|v|·dt)    // 重力 + 空気抵抗

// ③ 判定：長押し中は 1.05 /秒で 0↔1 を往復（ピンポン）
狙い通り = |power − 目印| ≤ 0.06
  → パワーを目印に補正して発射（＝小さな誤差は吸収され、狙い点にきっちり落ちる）
外した   → そのパワーの距離に着水（手前に落ちる／飛ばし過ぎる）

水面を半透明で被せる方式をやめ、シーンを一度テクスチャに描いてから水中の減衰で合成する方式にしています。 半透明だと「湖底の明るい砂」と「水の濃紺」の差が大きく、不透明度をどれだけ滑らかに変えても 見える所と見えない所の境目が線として出てしまうためです。

ドロップオフ

岸線からすぐ落ち込む急深型です（岸から 1 m で約 2 m、8 m で約 8 m）。浅場の魚は岸すぐ、深場の魚は遠投で狙い分けます。キャスト中の予測リングと水深表示がそのまま指標になります。

深い淵（ホール）

桟橋から見て左右どちらかの前方、岸から 26〜36 m 内側に半径 30 m。必ず水深 24 m 前後になるよう掘る量が決まるので、どの湖でもレジェンドの層（湖の主 14〜28 m / 白龍魚 17〜30 m）が成立します。

藻場

淵の反対側、岸から 14〜24 m 内側。必ず水深 2.5 m 前後。weed タグ（ライギョ・ブルーギル・バス）を中層〜底層で狙う場所（水深 2.5 m なので底層でも 2.2 m）。葦が密生します。

斜面の緩急

方角ごとに指数が変わるので、広い浅棚が続く岸と岸からすぐ落ちる急斜面が同じ湖に混在します。 さらに 1 段のかけあがり（最大 5.8 m の段差）が入り、水深 5m 付近で急に落ちるラインができます。

水中ストラクチャー

沈み岩と立ち枯れが 16〜23 個。水面上には出ないので キャストの邪魔はしませんが、肉食魚・藻場の魚 ×1.45／底物 ×1.3 の集魚効果があります。水中カメラ（V）で見えます。

底質

砂地・岩場・泥底の 3 種。底を釣るときだけ強く効きます（中層 0.35 乗・表層 0.1 乗）。 岩場はバス・ライギョ・鱒、泥底はコイ科と底物、砂地は底物と深場の魚に向きます。
岩場には転石が 600〜2400 個（描画品質で変わる）散らばるので、水中カメラで見れば底質が目で分かります。 砂地との境は底質の値でまばらにし、斜面ほど深く埋めて浮いて見えないようにしています。

歩ける範囲

地形高さ −0.55 m まで（水深 0.55 m まで）入れます。勾配 1.5 超の急斜面は登れません。中心から 460 m が世界の端。
