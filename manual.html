0単位と記号

長さ

ワールド 1 単位 = 1 m。魚の全長は cm。水深 m。

時間

式の dt は実時間の秒。ゲーム内時刻は実 30 秒で 1 時間（1 日 = 実 12 分）。

テンション比・残り距離・体力は 0〜1 の内部値。HUD のバーはそのまま％表示。

以下、sp は魚種データ、rod/line/bait は装備データ、F はファイト中の状態を指します。

1ファイト — 4つのメーターの正体

ヒット後の駆け引きは、次の 4 つの状態量だけで決まります。毎フレーム、この 4 つが更新され、 3 つの終了条件のどれかに触れた瞬間に決着します。

ラインテンション

F.tension / line.cap

糸に掛かっている張力。巻くと増え、離すと減る。line.cap（糸の強さ）に達した瞬間にラインブレイク。

残り距離

F.dist（1 = 着水点）

魚までの距離。ヒット時 0.88 から始まり、巻けば減り、放せば魚に引かれて増える。1.0 で逃走／0.03 で取り込み。

魚の体力

F.stamina（1 → 0）

魚のスタミナ。テンションを掛けている間だけ減る。減ると引く力が弱まり、突進しなくなり、水面に浮いてくる。

突進（ラン）

F.running / runTimer

周期的に発生する暴れ。発生中は引く力が 2 倍。「走った！」の表示中に巻くと一気にテンションが上がる。

毎フレームの更新式（実装そのまま）

// 引きの強さ。突進中は2倍、体力が尽きると半分になる
pull = F.pull0 * (F.running ? 2.0 : 1.0) * (0.5 + 0.5 * F.stamina)

if (巻いている) {
  resist  = clamp(1.70 - pull * 0.75, 0.35, 1.60)   // 強い魚ほど巻けない
  F.dist    -= rod.reel * 0.28 * resist * dt
  F.tension += (0.08 + pull * 0.55) * dt / rod.power
} else {
  F.dist    += pull * 0.032 * dt                    // 糸を出す=魚が遠ざかる
  F.tension -= (1.30 + pull * 0.30) * dt
  if (F.running) F.tension += pull * 0.30 * dt   // 走られると放しても張る
}
F.tension = clamp(F.tension, 0, line.cap * 1.2)

// 体力：テンション比が高いほど速く削れる
tRatio = clamp01(F.tension / line.cap)
F.stamina -= (0.022 + tRatio * 0.17 + (巻いている ? 0.02 : 0)) * dt / max(0.4, sp.sta)

// 決着
if (F.tension >= line.cap) → ラインブレイク
if (F.dist >= 1.0)          → 逃走
if (F.dist <= 0.03)         → 取り込み

src/game.js — _updateFight()

ファイト中は魚種とレア度を伏せています。パネルの見出しは代わりに pull0（= 種の str × サイズ係数）から求めた手応えを表示します： 軽い引き（<0.55）／まずまずの引き（<1.0）／強い引き！（<1.6）／かなり重い…！（<2.4）／とてつもない重さ…！。 サイズも含まれるので大きなコモンも「重い」になり、レア度は推測できません。 ヒット時のメッセージ・突進の警告・エラ洗いの発生も、レア度ではなく pull0 を基準にしています。

ファイトの型（魚種ごとの振る舞い）

魚種には fight で 型が1つ割り当てられています。型は上の更新式に掛ける倍率と追加イベントだけで、 新しいメーターや操作は増えません（1.0 なら従来と同じ挙動）。 fight が無い魚種は fightPattern() がタグ・体型から自動で決めます。

ジャンプの扱い

ジャンプは突進の途中で発生し、跳ね終わるまで突進が終わりません。 つまり「走ったら糸を送る」という基本ルールを守っていれば自動的に対応できます。 送れていれば魚が余計に消耗し（jumpDrain /秒だけ体力が減る）、 巻いたままだと張力の増加が jumpTension 倍になります。

首振りの扱い

数値そのものを揺らすのではなく、振っている間だけ巻き取り効率が shakeReel 倍に落ち、張力の増加が shakeGain 倍になります。 メーターは正直な値のままなので「振っている間は手を止める」という判断が生まれます。

型はレア度が偏らないように割り当てています（各型にコモン〜レア以上が混在）。 ファイト中に型が分かってもレア度や魚種は特定できません。

質問への回答

Q. 「魚の体力」とは？ 減ると何が起きる？ 魚のスタミナ F.stamina（1 → 0）です。テンションを掛けている間だけ削れ、 減ると次の 3 つが同時に起きます。
  • 引く力が落ちる：pull の係数 (0.5 + 0.5×stamina) が 1.0 → 0.5 に。つまり最大で半減。 引きが弱まると resist が上がるので巻き取り速度も上がり、加速度的に楽になります。
  • 突進しなくなる：stamina ≤ 0.16 で新しいランが発生しません。
  • 浮いてくる：見た目の泳層が lerp(0.35, 2.4, stamina) m と浅くなり、水面で暴れる演出になります。
減る速さは ÷ max(0.4, sp.sta)。つまり sp.sta（体力値）が大きい魚は「粘る」＝弱らせるのに時間が掛かります。 テンション比 0.7 を維持した場合の目安は (0.022 + 0.7×0.17 + 0.02) / sta ≒ 0.16 / sta /秒 → sta 1.0 の魚なら約 6 秒、sta 3.2 の湖の主なら約 20 秒でスタミナ切れ。 逆にテンションを掛けずに待っても魚は疲れません（0.022/sta しか減らない）。
Q. 「糸の強さ（line.cap）」とは？ テンションの上限＝切れる値そのものです。HUD のテンションバーは tension / cap を表示しているので、 cap が大きい糸は「同じ表示％に達するまでの余裕が大きい」＝巻ける時間が長くなることを意味します。
  • ナイロン 1.00 → ミスリル 2.80 で、切れるまでに耐えられる張力が 2.8 倍。
  • 張力の増加は (0.08 + pull×0.55) / rod.power /秒。0 から cap に達するまでの秒数は cap × rod.power / (0.08 + pull×0.55) です。
  • 体力削りは tension / cap の比で効くため、強い糸ほど「安全な範囲で強く引ける」＝魚を早く疲れさせられます。
Q. ロッドの「竿の力（power）」「巻取（reel）」の違い？ power はテンションの増加を割り算で抑える値（＝竿が引きを吸収する）で、tension += … / rod.power。 reel は巻き取り速度の倍率で、dist -= rod.reel × 0.28 × resist × dt。 power は「切れにくさ」、reel は「早さ」に効きます。ラインブレイクを減らしたいなら line.cap と rod.power、 ファイトを短くしたいなら rod.reel です。attract はファイトには無関係（アタリの速さと抽選）。
逃走（残り距離 1.0）は「巻けない」ことで起きます。 放している間、距離は pull × 0.032 /秒で増えます。強い魚の突進中（pull が 2 倍）は 放すだけで 0.2/秒以上取られることもあり、巻き取り（rod.reel×0.28×resist）が それを下回る装備だとどう操作しても逃げられます。これが装備の壁です。

目安にはなる

まわりを泳ぐ 22 匹も同じ rollSpecies(水深) で湧いているので、 見えている魚種＝その場所・その時刻に釣れる魚の目安になります。最初は自分の周り 6〜52 m に配置され、 78 m 以上離れる／水深 0.35 m 未満に乗り上げると 26〜58 m 先へ入れ替わります。

ただし条件は違う

3魚データ（全 34 種）

src/data.js の SPECIES をそのまま表にしています。 str＝引きの強さ、sta＝体力（粘り）、agg＝突進頻度。 内訳は魚 30 種＋ゴミ 4 種で、魚のうち 3 種は甲殻類（テナガエビ・ザリガニ・モクズガニ）です。 甲殻類は体型が魚と違うため専用メッシュで作られ、shape が shrimp / crayfish / crab になっています（扱いは魚と同じ。図鑑でも「魚」として数えます）。 カニの len は甲幅、wc はそれに合わせた係数です。

時間帯・天候の倍率

③④ に掛かる倍率です。時間帯は 朝 4:30–7:30 / 昼 7:30–16:30 / 夕 16:30–19:30 / 夜 それ以外。

5キャストの物理

キャストは「狙った距離に当てる」操作です。視線が水面と交わる点が狙い点で、そこに水色の輪が出ます。 メーターの緑の帯はその距離に必要なパワーの位置。帯の中で離すと狙い通りに落ちます。 

// ① 狙い点：視線と水面(y=0)の交点。見下ろすほど近く、水平で遠く
狙い距離 = clamp(視線が y=0 に達する水平距離, 最短キャスト, 50) m

// ② 目印：その距離に落ちるパワーを弾道の逆算（二分探索12回）で求める
仰角成分 = clamp(0.46 + pitch × 0.55, 0.16, 0.95)
初速     = lerp(4.5, 28.5, power) m/s
毎フレーム: v.y −= 9.8·dt ;  v ×= (1 − 0.0055·|v|·dt)    // 重力 + 空気抵抗

// ③ 判定：長押し中は 1.05 /秒で 0↔1 を往復（ピンポン）
狙い通り = |power − 目印| ≤ 0.06
  → パワーを目印に補正して発射（＝小さな誤差は吸収され、狙い点にきっちり落ちる）
外した   → そのパワーの距離に着水（手前に落ちる／飛ばし過ぎる）

糸の最大長 = 62 m（超えるとその場で着水／待機中に超えると強制回収）

狙い通りの効果

驚かす半径が 2.6+power×2.2 → 1.4 m に縮小、アタリまでの時間が ÷1.18。 遠投でも足元でも同じ条件で成立するので、浅場狙いが不利にならないのが以前との違いです。

糸が掛かる判定

糸（ロッド先端 → ウキ）が桟橋・陸の張り出し・岩を貫通する向きには投げられません。 ためている間に判定して着水予測リングが赤くなり、それでも投げると着水時に 「〜に糸が掛かった」で自動回収されます。待機中に歩いて障害物を挟んだ場合も同じです。 

// 桟橋：線分 vs OBB（スラブ法）。床（桁を含む厚み）と先端の手すりの2箱
床  : along[0, 長さ] × side[−1.62, 1.62] × y[床−0.42, 床+0.18]
手すり: along[長さ−2.3, 長さ] × 同 × y[床−0.42, 床+1.05]

// 地形・岩：たるみ込みの曲線を 1.6m 刻みでサンプリング
サンプル数 = clamp(ceil(距離 / 1.6), 8, 40)
y(t) = lerp(先端, 着水点, t) − sin(πt) × min(距離×0.16, 1.2) × たるみ
掛かる条件: y(t) + 0.22 < 地面の高さ（または岩の上端）

地形と水深

湖はシードから毎回生成されます（新しく始めるたびに別の湖／ポーズ画面でいつでも引き直し可）。 同じシードなら必ず同じ湖になり、描画品質を変えても地形は変わりません。 生成は src/lakefield.js にあり、採用前に検証を通すことで「破綻」と「詰み」を防いでいます。 

// 湖底の高さ（over = 岸線からの距離、k = 1 − r/岸線半径）
岸線半径 = clamp(130 + 34 × ノイズ(方角), 92, 168)     // 角度だけの関数 → 湖は常に1つ
水中: h = −(26 × k^0.6 × smoothstep(0, 0.075, k)) + 湖底ノイズ×1.35k − 淵 + 藻場
陸上: h = over × 0.15 + 丘ノイズ×7.5 + 山リッジ×105×smoothstep(70, 320, over)

// 桟橋：方角はシードでランダム。岸線を二分探索して位置を決める
桟橋 = 岸線 +3.5m（陸側） 〜 −26m（沖側）
床の高さ = clamp(陸側の最高地面 + 0.5, 1.15, 2.6)     // 地形に埋まらないよう追従

// 深い淵：目標水深になるよう掘る量を決める（レジェンドの層を保証）
淵の深さ = clamp(24 − その場の水深, 0, 16)、岸際は smoothstep(0, 0.12, k) でフェード
// 藻場：目標水深まで底上げ。ただし必ず 1.2m の水を残す（陸ができない）
底上げ = min(clamp(その場の水深 − 2.5, 0, 12) × ガウス, その場の水深 − 1.2)
